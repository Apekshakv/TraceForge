Trace every leak. Expose every hidden payload. Prove every finding.

TraceForge is an AI-powered, defensive security tool that traces leaked images to their source, flags images that may hide data, and keeps tamper-evident evidence of what it finds. It is a CyberForge hackathon project (theme: AI in Cybersecurity).

This repository holds the front-end prototype of TraceForge, built with plain HTML, CSS and JavaScript. Page 1 (Watermark) works today: upload an image and TraceForge extracts its basic metadata, entirely in your browser.
